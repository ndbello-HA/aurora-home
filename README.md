# Aurora Home

Launcher personalizado para TVs Samsung Tizen, instalado pelo [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller).

- Menu lateral, destaque, relógio, clima (Open-Meteo), atalhos de apps em liquid glass
- Linha "Casa" para controlar o Home Assistant (opcional)
- Navegação pelo controle remoto

## Instalar
No TizenBrew Installer: **Install from GitHub** → `ndbello-HA/aurora-home`

## Configurar
Edite `js/config.js` (cidade do clima, apps, Home Assistant). Não coloque tokens neste repositório público.

## Desinstalar
Na TV: Apps → Configurações → Aurora Home → Excluir.
